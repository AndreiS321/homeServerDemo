# Home Server Infrastructure (IaC)

Автоматизированная система конфигурации домашнего сервера.

## Описание

Данный проект представляет из себя набор **Ansible** плейбуков и ролей, с помощью которых я конфигурирую мой домашний сервер. Он предназначен для автоматизированного развертывания, настройки и управления сервисами на сервере.

## Основные возможности

* **Автоматизация (IaC):** Создание отдельного ansible пользователя, настройка сети, настройка docker и развёртывание всех сервисов выполняется одной командой.
* **Мониторинг и Observability:** Внедрен стек мониторинга (VictoriaMetrics + Grafana) для сбора метрик системы и контейнеров в реальном времени.
* **Безопасность и Proxy:** Автоматизированная настройка Nginx в качестве реверс-прокси перед остальными сервисами с автоматическим получением и обновлением SSL-сертификатов через Certbot (через DNS challenge).
* **CI/CD:** Развертывание self-hosted GitHub Runner для выполнения workflows на своём сервере.

## Технологический стек

* **Управление конфигурацией:** Ansible (Roles, Playbooks)
* **Контейнеризация:** Docker, Docker Compose
* **Сети и безопасность:** Nginx, Certbot, Ansible Vault
* **Мониторинг:** VictoriaMetrics, vmagent, Grafana, cAdvisor, Node Exporter
* **Сервисы:** Home Assistant, GitHub Actions Runner

## Архитектура сервисов

| Сервис | Назначение |
| :--- | :--- |
| **Nginx** | Реверс-прокси, управление трафиком и SSL |
| **VictoriaMetrics** | Хранилище временных рядов (metrics storage) |
| **Grafana** | Визуализация метрик |
| **Home Assistant** | Управление умным домом |
| **GitHub Runner** | Выполнение CI/CD пайплайнов |

## Быстрый старт

1. Настройте `hosts.yml` под свою конфигурацию.
2. Создайте необходимые конфигурационные файлы в директориях `group_vars` и `host_vars`, используя примеры `*.yml.example` в качестве шаблонов.
3. Запустите основной плейбук:
   ```bash
   ansible-playbook -i hosts.yml playbooks/deploy_all.yml
   ```
